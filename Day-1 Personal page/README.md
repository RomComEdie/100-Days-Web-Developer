# 🚀 100 Days of Web Development

Welcome to my **100 Days of Web Development** journey.

This repository documents my journey of learning, practicing, and building web applications over 100 days.

My main focus is **PHP and backend web development**, while also exploring **JavaScript, Laravel, React, Node.js, MySQL, Git, and modern web development**.

The goal of this challenge is not just to complete 100 days, but to build practical skills through consistent learning, hands-on projects, experimentation, debugging, and real-world problem solving.

---

## 🎯 Goals

* Build a strong foundation in web development
* Improve PHP and backend development skills
* Learn and explore Laravel
* Strengthen JavaScript fundamentals
* Explore React for frontend development
* Learn the fundamentals of Node.js
* Improve MySQL and database skills

* Improve debugging and problem-solving skills

## 📚 Learning Approach

This challenge focuses on **learning by doing**.

The general process is:

```text
Learn
  ↓
Practice
  ↓
Build
  ↓
Debug
  ↓
Understand
  ↓
Improve
```

Some days may focus on learning a single concept, while others may involve building a complete project.

Not every day needs to produce a large application. Small experiments, exercises, debugging sessions, and improvements are also part of the journey.

## 🌐 Main Focus

Although this challenge covers multiple technologies, **PHP remains the main focus** of my web development journey.

Laravel will be explored as a PHP framework, while JavaScript, React, and Node.js will be used to understand modern frontend and backend development.

The purpose is to understand both the fundamentals and how different technologies can work together in real-world applications.

## 🔐 Security Awareness

Security is an important part of building web applications.

Throughout the journey, I will also practice writing more secure code and understanding common web security concepts such as:

* Input validation
* Authentication
* Authorization
* Password security
* SQL injection prevention
* XSS prevention
* CSRF protection
* Session security
* Secure file uploads
* API security

The goal is to learn how to build applications that are not only functional, but also more secure and responsible.
